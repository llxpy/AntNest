🐜 AntNest

基于蚁巢架构的本地 AI 运维平台。蚁后理解意图、拆解任务，工蚁隔离执行。全系统访问，不走云端。

下载安装包 查看源码
工作原理

核心能力

不只是聊天，而是能真正操作你系统的 AI 伙伴

🖥️

全系统访问

完整 Shell 集成——不是沙箱子集。磁盘、注册表、网络、进程，蚁后都能碰。

🔒

进程级隔离

每个工蚁是独立 Python 进程。执行崩溃不影响主程序，安全边界清晰。

🧠

任务拆解

蚁后自动将复杂指令拆分为子任务，派遣多个工蚁并行执行，最后汇总结果。

📦

Skills 系统

可扩展的技能包。选中 Skill 注入上下文，让蚁后获得专项能力——代码审查、文档生成等。

🔌

MCP 集成

接入 MCP 服务器扩展工具链。文件系统、数据库、API——工蚁可以调用外部服务。

📱

Android 客户端

原生 Android 应用，Kotlin + Jetpack Compose。手机上也能调度蚁后。

快速开始

几分钟内启动你的第一个蚁后

📋 系统要求

  • Windows 10/11（64 位）
  • Python 3.12+
  • uv（首次运行自动安装）
  • WebView2 Runtime（Win11 自带）

⚡ 安装包（推荐）

下载 AntNest-Setup.exe，双击运行。自动安装依赖。

AntNest-Setup.exe → 双击 → 完成

🐍 源码运行

适合开发者。克隆仓库后用 uv 启动。

git clone https://github.com/llxpy/AntNest.git cd AntNest uv sync uv run python prototype_antnest.py

🤖 pip 安装

通过 pip/uvx 安装为命令行工具。

pip install antnest # 或 uvx antnest
